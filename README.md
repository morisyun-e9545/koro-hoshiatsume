# コロのほしあつめ

スーツ姿のコロさんが星のかけらを集めながら走る、ブラウザで遊べる横スクロールアクションゲームです。
キャラクター、ステージ、グラフィック、音楽はすべてこのプロジェクトのオリジナルです。

## 遊び方

`index.html` をブラウザで開くだけで遊べます。インストールやビルドは不要です。

| 操作 | キーボード | スマホ |
| --- | --- | --- |
| 移動 | ← → / A D | ◀ ▶ |
| ジャンプ | Space / ↑ / W / Z / J | A |
| ダッシュ | X / K（押しながら） | B（押しながら） |
| ポーズ | P / Esc | Ⅱ ボタン |
| 音のオンオフ | M | ♪ ボタン |

- ライフは3つ。穴に落ちるか敵やトゲに当たると減ります。
- 木箱を下からたたくと、星、ハート、かぜマントが出ます。
- かぜマントがあると空中でもう一回ジャンプでき、ダメージも一度だけ防げます。
- ランタンは中間地点です。落ちてもそこから再開できます。
- 敵は踏んで倒せます。トゲボウ（紫のトゲを背負った敵）だけは踏めません。

全3ステージで、最後の「ほしぞら洞窟」にはボスがいます。

## GitHub Pages で公開する

1. GitHub のリポジトリで **Settings → Pages** を開く
2. **Source** を `Deploy from a branch`、ブランチを `main`、フォルダを `/ (root)` にして保存する
3. 少し待つと `https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べるようになる

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | ページの土台 |
| `style.css` | 画面表示（HUD、メニュー、タッチボタン） |
| `js/levels.js` | ステージの地形と配置。ステージを作り変えるならここ |
| `js/sprites.js` | キャラクター、地形、背景のグラフィック生成 |
| `js/audio.js` | 効果音とBGM |
| `js/game.js` | 物理、当たり判定、描画、画面遷移 |

開発用に、URL の末尾へ `?god` を付けると無敵に、`?debug` を付けるとコンソールから `KoroDebug` を使えます。
